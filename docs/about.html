About this calculator

This RPN calculator is built with a static site (Vite + Vanilla JS) using client-side logic in /src/app.js, and styles in /src/styles.css.

The majority of the code was written by JUNIE AI (an autonomous programmer by JetBrains), with iterative guidance and requirements provided by the project owner.

Source code: github.com/pjcunningham/rpn.calc

Skins

This app includes multiple visual skins you can pick from the top-right Skin menu:

  • Green (classic CRT)
  • Amber (1980s amber phosphor)
  • Windows 3.1 (light gray, navy accents)
  • Apple (Modern) — light, clean, blue accents
  • Commodore 64 (blue background, light blue text)
  • BSOD (blue screen, white text)
  • USSR NIXIE (1970s Nixie tube orange glow)
  • Sinclair LED (early Sinclair Cambridge LED)
  • HP-48SX LCD (dot-matrix green/gray LCD)
  • Sonnet 18 (Shakespeare parchment & ink)
